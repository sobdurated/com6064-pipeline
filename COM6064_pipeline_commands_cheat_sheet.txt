COM6064 Pipeline Command Cheat Sheet
====================================

Use these commands from the project root folder.

Example project root:
C:\Users\HP\OneDrive\Desktop\Pull test 4\com6064-pipeline-main (2)\com6064-pipeline-main


1. Activate virtual environment
-------------------------------

PowerShell:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1

You are ready when you see:

(venv) PS ...


2. Install requirements
-----------------------

pip install -r requirements.txt


3. Create or edit .env
----------------------

12. Test redundancy
-------------------

Run the same command twice.

First run:

$json='{"max_topics":3,"num_results":3,"province":"Ankara","district":"Nallıhan","category":"all"}'
python pipeline.py --interactive --input $json

Choose:

2

Second run:

python pipeline.py --interactive --input $json

Choose:

2

Expected result:
MongoDB should not add duplicate posts.
The script should skip completed requests or insert 0 new posts.

The script searches again.

Only new clean posts should be saved.


14. Meaning of max_topics and num_results
-----------------------------------------

num_results:
How many search result URLs Serper should return.

max_topics:
How many of those URLs the scraper should actually scrape.

Example:

"num_results":3
"max_topics":3

Meaning:
1 Serper API call.
Up to 3 URLs returned.
Up to 3 topic URLs scraped.
Each topic can scrape up to 5 pages.


15. API usage estimate
----------------------

1 search query = 1 Serper API request.

One province + one district + one category = 1 search query.

Example:

Ankara + Nallıhan + yemek = 1 API request

If you use:
districts × categories

Example:
973 districts × 5 categories = about 4,865 API requests.

21. Common errors
-----------------

Error:
ModuleNotFoundError

Fix:
pip install -r requirements.txt

Error:
Activate.ps1 cannot be loaded

Fix:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1

Error:
JSON input broken in PowerShell

Fix:
Use variable format:

$json='{"max_topics":1,"num_results":1,"province":"Ankara","district":"Nallıhan","category":"yemek"}'
python pipeline.py --interactive --input $json
