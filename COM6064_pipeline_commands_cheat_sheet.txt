Use these commands from the project root folder.

PowerShell:


# 17. Bulk protection warning

Large automatic runs may trigger bulk protection.

Example:

```powershell
$json='{"max_topics":5,"num_results":10}'
python pipeline.py --interactive --input $json
```

Fix:

Add:

```json
"confirm_bulk":true
```

Example:

```powershell
$json='{"max_topics":5,"num_results":10,"confirm_bulk":true}'
python pipeline.py --interactive --input $json
```

# 20. Meaning of max_topics and num_results

`num_results`

How many search result URLs Serper should return.

`max_topics`

How many of those URLs the scraper should actually scrape.

Example:

```json
"num_results":3
"max_topics":3
```

Meaning:

```text
1 Serper API call
Up to 3 URLs returned
Up to 3 topic URLs scraped
Each topic can scrape up to 5 pages
```

# 21. API usage estimate

```text
1 search query = 1 Serper API request
```

One province + one district + one category = 1 search query.

Example:

```text
Ankara + Nallıhan + yemek = 1 API request
```

If you use:

```text
districts × categories
```

Example:

```text
973 districts × 5 categories = about 4,865 API requests
```

# 24. Check MongoDB records

In MongoDB Atlas filter:

```json
{
  "location.province": "Ankara",
  "location.district": "Nallıhan"
}
```

For category:

```json
{
  "location.province": "Ankara",
  "location.district": "Nallıhan",
  "category": "yemek"
}
```

For tags:

```json
{
  "post_tags": {
    "$all": ["Ankara", "Nallıhan", "yemek"]
  }
}
```

# 27. Common errors

```text
ModuleNotFoundError
```

```powershell

```


Fix:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

